# Project Memory: FreeStyle Libre Live Blood Sugar Connector (Taskbar Tray & Local Analytics)

## Project Overview
- **Repository**: `konradschrein-star/freestyle-libre-live-bloodshugar-connector`
- **Owner**: Konrad (Titan Media Empire)
- **Goal**: Real-time FreeStyle Libre (Libre 3 / LibreLinkUp) blood sugar monitor in the Windows taskbar system tray (next to clock) with live color-coded numbers, trend arrows, local SQLite persistence, German/English UI, 100% GDPR/DSGVO compliance (zero cloud telemetry), and an optional local web dashboard.
- **Stack**: Python 3.11+ / `pystray` / `Pillow` / `httpx` / `sqlite3` / `FastAPI` + `Chart.js` / Windows Registry Autostart / PyInstaller.

## Architectural Guidelines
1. **Taskbar Integration**: High-DPI dynamic tray icon rendering real-time glucose value + trend arrow + color status (🟢 in-range, 🟡 warning, 🔴 critical).
2. **Abbott LibreLinkUp Client**: Robust async client with auto-region discovery (`api-eu`, `api-de`, `api-eu2`, `api-us`), bearer token refresh, exponential backoff, and full error recovery.
3. **Data Layer & Privacy**: 100% Local SQLite storage (`blood_sugar.db`). Zero external telemetry. Complete GDPR compliance.
4. **Localization**: Full German default with English toggle (`de` / `en`).
5. **Analytics & Dashboard**: Embedded local web dashboard (`http://localhost:8765`) for 24h/7d charts, Time in Range (TIR), AGP metrics, and CSV/JSON export.
6. **Packaging**: Quick launcher `.bat` scripts and PyInstaller build script for standalone Windows `.exe`.
